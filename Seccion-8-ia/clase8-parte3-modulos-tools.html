Módulos de Tools en IA

La IA deja de solo responder texto y empieza a hacer cosas reales. Con Tools, el modelo decide qué acciones ejecutar, cuándo y con qué parámetros.

🔥 El salto de la Parte 2 a la Parte 3
Parte 1 y 2 — IA que responde con contexto
"Lee, recuerda y genera texto"

La IA toma el prompt, usa la memoria y devuelve una respuesta en texto. El workflow ejecuta lo que el humano decidió programar.

Parte 3 — IA que actúa con Tools
"Decide qué acción ejecutar y la ejecuta"

La IA tiene acceso a un conjunto de herramientas. Cuando el usuario pide algo, el modelo decide solo qué tool usar, con qué parámetros, y n8n lo ejecuta.

Sección 2

Cómo Funcionan los Tools

El mecanismo detrás: Function Calling. La IA no ejecuta las tools — decide cuáles usar y con qué argumentos. n8n es quien las ejecuta.

⚙️ El ciclo completo de un Tool call
// PASO 1: Definir las tools disponibles para la IA tools: [ { "name": "buscar_lead", "description": "Busca un lead en la base de datos por email", "parameters": { "email": { "type": "string", "required": true } } }, { "name": "crear_lead", "description": "Crea un nuevo lead en el CRM", "parameters": { "nombre": { "type": "string", "required": true }, "email": { "type": "string", "required": true } } } ] // PASO 2: Usuario envía un mensaje "¿Existe un lead llamado Carlos con email carlos@x.com?" // PASO 3: La IA decide qué tool usar (NO la ejecuta) → tool_call: { "name": "buscar_lead", "arguments": { "email": "carlos@x.com" } } // PASO 4: n8n intercepta el tool_call y lo ejecuta → Sheets SEARCH: email == "carlos@x.com" → resultado: { nombre: "Carlos", estado: "nuevo" } // PASO 5: n8n devuelve el resultado a la IA → tool_result: { "lead": { "nombre": "Carlos", "estado": "nuevo" } } // PASO 6: La IA genera la respuesta final → "Sí, Carlos existe como lead en estado 'nuevo'."
🔑 Reglas del Function Calling
  • →
    La IA decide, n8n ejecuta. El modelo solo produce JSON con el nombre de la tool y sus argumentos. Nunca corre código directamente.
  • →
    La descripción importa más que el nombre. La IA elige la tool basándose en su descripción. Una descripción clara = tool usada correctamente.
  • →
    Puede llamar varias tools en secuencia. Si necesita buscar Y luego actualizar, hace dos tool_calls consecutivos antes de responder.
  • ✗
    No dar tools que no necesita. Demasiadas tools confunden al modelo. Máximo 10-15 por agente, bien enfocadas en el dominio.
🏗️ Implementación en n8n — IF Switch por tool_call
// n8n intercepta la respuesta de la IA IF respuesta contiene tool_calls: → extraer nombre de la tool → extraer argumentos (JSON) ↓ Switch por nombre de tool: "buscar_lead" → nodo Sheets Search "crear_lead" → nodo Sheets Append "enviar_slack" → nodo Slack "buscar_web" → nodo HTTP Search default → log "tool desconocida" ↓ // Devolver resultado a la IA en el historial messages.push({ role: "tool", tool_call_id: id, content: JSON.stringify(resultado) }) // → nueva llamada a la IA con el resultado
Categoría 1 de 5

Tools de Datos

Leer, escribir y actualizar bases de datos, hojas de cálculo y CRMs. La IA accede a la información real del negocio bajo demanda.

📊
Tools de datos · Google Sheets · CRM · Base de datos
La IA consulta y modifica datos reales
Las tools de datos le dan a la IA acceso de lectura y escritura a las fuentes de datos del negocio. El modelo puede consultar cuántos leads hay, crear un registro nuevo, actualizar un estado o buscar un cliente específico — todo desde una conversación natural.
📖 Leer registros➕ Crear filas ✏️ Actualizar estado🔍 Buscar por campo📊 Agregar métricas
⚙️ Definición de tools de datos para la IA
// Tool 1: Leer leads del día { "name": "obtener_leads_hoy", "description": "Devuelve todos los leads recibidos en el día de hoy", "parameters": {} // sin parámetros } // n8n ejecuta: Sheets READ donde fecha == hoy // Tool 2: Buscar cliente { "name": "buscar_cliente", "description": "Busca un cliente por email o nombre en la base de datos", "parameters": { "query": { "type": "string", "required": true, "description": "Email o nombre a buscar" } } } // Tool 3: Actualizar estado { "name": "actualizar_estado_lead", "description": "Cambia el estado de un lead (nuevo/contactado/calificado/cerrado)", "parameters": { "lead_id": { "type": "string" }, "estado": { "type": "string", "enum": ["nuevo","contactado","calificado","cerrado"] } } }
🏢 Casos reales
💼
"¿Cuántos leads tenemos esta semana?"
IA llama obtener_leads_semana() → Sheets → responde con el número y breakdown por día
🔄
"Marca a Carlos como calificado"
IA llama buscar_cliente("Carlos") → obtiene ID → llama actualizar_estado("clt_123", "calificado")
📈
"¿Cuál es nuestra tasa de conversión?"
IA llama obtener_metricas() → calcula en la respuesta → comunica el porcentaje
Categoría 2 de 5

Tools de Código

La IA ejecuta cálculos, transforma datos, genera archivos o corre scripts. Sin herramientas de código, la IA puede alucinar resultados matemáticos.

⚡
Tools de código · Calculadora · Transformaciones · Scripts
Cálculos exactos y transformaciones deterministas
Los LLMs son notoriamente malos en aritmética compleja. Una tool de código es la solución: la IA identifica qué calcular, pasa la expresión a la tool, el código la ejecuta con precisión 100% y devuelve el resultado. Aplica a cálculos, conversiones, formateo de datos y generación de reportes.
🧮 Cálculos exactos🔄 Transformar datos 📄 Generar CSV/JSON📅 Fechas y tiempos💱 Conversiones
⚙️ Tools de cálculo — implementación en n8n
// Tool: calculadora con mathjs { "name": "calcular", "description": "Evalúa una expresión matemática con precisión. Usar para sumas, porcentajes, promedios, etc.", "parameters": { "expresion": { "type": "string", "description": "Ej: '2300000 * 0.19'" } } } // n8n ejecuta con Function node: const math = require('mathjs'); const expresion = $input.first().json.expresion; const resultado = math.evaluate(expresion); return [{ json: { resultado, expresion } }]; // Resultado al modelo: // { "resultado": 437000, "expresion": "2300000 * 0.19" }
⚙️ Más tools de código útiles
// Tool: convertir moneda "convertir_moneda": (monto, de, a) → GET api.exchangerate.com/{{de}}/{{a}} → calcular: monto × tasa → resultado: { convertido: X, tasa: Y } // Tool: calcular fecha "dias_desde": (fecha) → Function: Date.now() - new Date(fecha) → resultado: { dias: 45 } // Tool: formatear datos para reporte "generar_resumen_stats": (array_numeros) → Function: min, max, promedio, mediana → resultado: estadísticas completas // Tool: generar CSV "array_a_csv": (datos, columnas) → Function: convertir JSON → CSV string → resultado: string listo para descargar
⚠️
Nunca confíes en la IA para aritmética crítica. Los LLMs pueden calcular mal 23% de $1.847.500. Siempre usa una tool de código para cualquier cálculo financiero, tributario o estadístico. La precisión es 100% con código, ~80% con el modelo solo.
Categoría 3 de 5

Tools de APIs Externas

La IA llama a servicios del mundo real: clima, mapas, pagos, CRMs, ERPs. Cualquier API con endpoint se convierte en una tool disponible para el agente.

🌐
Tools de APIs · HTTP Request · Servicios externos
El agente se conecta con cualquier servicio
Cada tool de API es un wrapper alrededor de un HTTP Request. La IA decide cuándo llamarla y qué parámetros enviar. n8n ejecuta el request, recibe la respuesta y se la devuelve al modelo. El agente puede consultar clima, geocodificar, procesar pagos o leer datos de cualquier SaaS.
🌤️ Clima🗺️ Geolocalización 💳 Pagos🤖 Otras IAs📱 Redes sociales
⚙️ Ejemplos de tools de API en n8n
// Tool: Consultar clima { "name": "obtener_clima", "description": "Obtiene el clima actual de una ciudad", "parameters": { "ciudad": { "type": "string" } } } → n8n: GET api.open-meteo.com/v1/forecast?city={{ciudad}} → resultado: { temp: 18, estado: "nublado" } // Tool: Consultar estado de pago { "name": "verificar_pago", "description": "Verifica si un pago fue procesado exitosamente", "parameters": { "payment_id": { "type": "string" } } } → n8n: GET api.stripe.com/v1/charges/{{payment_id}} → resultado: { status: "succeeded", amount: 150000 } // Tool: Llamar a otra IA (encadenar modelos) { "name": "analizar_imagen", "description": "Analiza el contenido de una imagen con vision IA", "parameters": { "url_imagen": { "type": "string" } } } → n8n: POST api.openai.com/v1/chat con gpt-4o vision
🏢 Casos reales con tools de API
🚚
"¿Dónde está mi pedido?"
IA → rastrear_envio(num_guia) → API transportadora → responde con ubicación actual y ETA
💳
"¿El pago de Laura fue aprobado?"
IA → verificar_pago(email) → Stripe API → "Sí, $450.000 aprobado el 15/01"
📍
"¿A cuánto tiempo está el cliente?"
IA → calcular_ruta(origen, destino) → Google Maps API → "A 23 minutos en coche"
🤖
Encadenar IAs: GPT-4 decide el flujo → llama tool → Claude analiza un documento → devuelve síntesis a GPT-4 para responder
Categoría 4 de 5

Tools de Búsqueda

La IA accede a información actualizada del mundo real. Web search, búsqueda en documentos propios y consulta de bases de conocimiento internas.

🔍
Tools de búsqueda · Web · Docs · Base de conocimiento
Información actualizada más allá del entrenamiento
El conocimiento de los LLMs tiene un corte de entrenamiento. Las tools de búsqueda les dan acceso a información real y actualizada: precios de hoy, noticias de esta hora, documentación de tu empresa, o cualquier página web. La IA decide buscar cuando necesita datos que no tiene.
🌐 Web search📄 Buscar en docs 🧬 Búsqueda vectorial📰 Noticias actuales💰 Precios en tiempo real
⚙️ Tool: búsqueda web en tiempo real
// Definición de la tool { "name": "buscar_web", "description": "Busca información actual en internet. Usar cuando necesites datos recientes o noticias", "parameters": { "query": { "type": "string", "description": "Términos de búsqueda" } } } // n8n ejecuta con Serper / Google Search API HTTP POST https://google.serper.dev/search headers: { "X-API-KEY": "{{API_KEY}}" } body: { "q": query, "num": 5 } // Retorna al modelo: { "resultados": [ { "titulo": "...", "snippet": "...", "url": "..." } ]} // La IA sintetiza los resultados en su respuesta
⚙️ Tool: buscar en documentación interna
// Usar el vector store de la Parte 2 { "name": "buscar_documentacion", "description": "Busca en los manuales, políticas y FAQs de la empresa. Usar para preguntas sobre productos, precios o procesos", "parameters": { "pregunta": { "type": "string" } } } // n8n ejecuta: 1. Embed la pregunta → OpenAI Embeddings 2. Buscar similares → Supabase / Pinecone 3. Retornar top 3 chunks relevantes // La IA responde citando la fuente exacta // en vez de inventar la respuesta

Categoría 5 de 5

Tools de Acción

La IA no solo responde — actúa. Envía notificaciones, crea tareas, manda emails, dispara otros workflows. El agente se convierte en un ejecutor autónomo.

🚀
Tools de acción · Notificaciones · Tareas · Workflows
El agente hace cosas, no solo dice cosas
Las tools de acción son las más poderosas y las más peligrosas. Le dan a la IA la capacidad de modificar el mundo: enviar mensajes, crear registros, activar procesos. Un agente bien configurado puede resolver un ticket completo — leer, analizar, responder y cerrar — sin intervención humana.
💬 Enviar Slack📧 Mandar email 📝 Crear tarea⚡ Disparar workflow📱 Notif WhatsApp
⚙️ Tools de acción más usadas
// Tool: Enviar mensaje a Slack { "name": "notificar_equipo", "description": "Envía un mensaje al canal de Slack del equipo de ventas", "parameters": { "mensaje": { "type": "string" }, "urgente": { "type": "boolean", "default": false } } } // Tool: Crear tarea en CRM { "name": "crear_tarea", "description": "Crea una tarea de seguimiento asignada a un vendedor", "parameters": { "titulo": { "type": "string" }, "asignado_a": { "type": "string" }, "vence_en": { "type": "string", "description": "Ej: '2 días'" } } } // Tool: Disparar un sub-workflow { "name": "iniciar_onboarding", "description": "Inicia el proceso de onboarding para un nuevo cliente", "parameters": { "cliente_id": { "type": "string" } } } → n8n: Execute Workflow "Onboarding-Cliente"
🛡️ Seguridad en tools de acción
⚠️
Confirmación humana para acciones irreversibles. Antes de enviar email masivo o eliminar registros, el agente debe pedir confirmación explícita al usuario
🔒
Scope mínimo. Si el agente solo necesita leer Slack, no darle la tool de escribir. Principio de mínimo privilegio también para IA
📋
Log de todas las acciones ejecutadas. Registrar qué tool usó, cuándo y con qué argumentos — auditoría completa del agente
🚫
Límites de uso. Máximo N acciones por sesión para evitar loops o comportamientos inesperados en producción

Sección 9

Entregable, Buenas Prácticas y Bonus

El agente con tools que debes construir, los errores que debes evitar y el mapa completo de la Clase 8 ensamblada.

✅ Entregable — agente con mínimo 3 tools funcionando
  • ✓
    Al menos 3 tools definidas con descripción clara
    Una de datos, una de búsqueda y una de acción. Cada tool con name, description y parameters bien documentados.
  • ✓
    Switch en n8n que enruta por nombre de tool
    La respuesta de la IA se evalúa: si contiene tool_call, el Switch dirige a la rama correcta.
  • ✓
    Resultado de la tool devuelto a la IA
    El resultado de cada tool se agrega al historial de mensajes con role "tool" antes de la siguiente llamada al LLM.
  • ✓
    Probado con una conversación de 2 pasos
    Un mensaje que dispara una tool, y una respuesta del usuario que dispara una acción basada en el resultado anterior.
  • ✓
    Log de tools usadas
    Registrar en Sheets qué tool usó, cuándo y con qué argumentos. Auditoría básica del agente.
