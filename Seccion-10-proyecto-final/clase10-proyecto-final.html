Sección 3

Los 8 Módulos del Sistema

El sistema no es un solo workflow gigante. Es 8 módulos independientes que se comunican entre sí. Cada módulo tiene responsabilidad única, puede probarse por separado y puede reemplazarse sin romper el resto.

📥
Módulo 1
Captura y Validación
Recibe leads desde múltiples canales: formulario web, webhook, email, WhatsApp. Normaliza y valida los datos. Los inválidos van a una hoja de errores.
WebhookCodeIF guardiánSheets errores
🎯
Módulo 2
Scoring y Clasificación
Calcula el score del lead (0–100) según datos disponibles, fuente y palabras clave. Clasifica en VIP, caliente, medio o frío. La IA refina la clasificación en casos ambiguos.
Code scoringOpenAISwitch 4 rutas
💼
Módulo 3
CRM y Pipeline
Registra el lead en Google Sheets con todos sus datos y estado inicial. Gestiona las transiciones de estado: Nuevo → Contactado → Interesado → Cliente. Un registro por evento.
Sheets AppendSheets UpdateMerge
👤
Módulo 4
Asignación Automática
Asigna el lead al vendedor correcto según prioridad. VIP → director. Caliente → senior. Medio → equipo general. Frío → nurture automático. Notificación inmediata al asignado.
Code asignaciónSlackCalendarSheets Update
📧
Módulo 5
Secuencia de Emails + IA
Email de bienvenida inmediato generado por IA con el nombre e interés del lead. Follow-up a las 24h. Recordatorio a los 3 días si no responde. Wait entre cada email.
OpenAIGmailWait x2IF sin respuesta
🔀
Módulo 6
Lógica Operacional
Router inteligente que toma decisiones según tipo de solicitud (soporte, ventas, facturación). Detecta urgencia por palabras clave. Activa SLA enforcement automático.
IF x3Switch tipoCode prioridadWait SLA
🔌
Módulo 7
Integraciones Externas
Conexión con servicios externos: Slack para notificaciones, Google Calendar para tareas, API de enriquecimiento de datos (Clearbit / Apollo) para obtener más info del lead automáticamente.
HTTP RequestSlackGoogle CalendarClearbit API
📊
Módulo 8
Logging y Dashboard
Registra cada evento del sistema en una hoja de log. Dashboard automático en Sheets con métricas: leads por estado, tasa de conversión, tiempo de respuesta. Error Trigger para fallos.
Sheets logError TriggerCron diarioResumen Slack
💡
Un workflow por módulo, no un megaworkflow. n8n permite llamar a un workflow desde otro (nodo Execute Workflow). Si un módulo falla, los demás siguen funcionando. Si necesitas cambiar la lógica de scoring, solo tocas el Módulo 2 sin tocar nada más.

Sección 5

Construcción Paso a Paso

El orden importa. Construir en la secuencia correcta significa que puedes probar cada módulo antes de conectarlo al siguiente y no llegar al final con un error imposible de diagnosticar.

🗺️ Roadmap de construcción — 10 pasos ordenados
Paso 1 — Fundación
Definir y preparar Google Sheets
Crear las 4 hojas (Leads, Log, Errores, Dashboard) con los headers correctos. Sin esto, ningún nodo de Sheets funcionará.
30 minSin n8n
Paso 2 — Módulo 1
Webhook + validación + guardado básico
Crear el webhook, el nodo Code de validación y el Sheets Append. Probar con 3 leads distintos antes de avanzar.
45 minClase 1–2
Paso 3 — Módulo 2
Scoring con Code + llamada inicial a IA
Añadir el nodo Code de scoring y el primer nodo OpenAI para clasificación. Verificar que el campo segmento tiene el valor correcto para cada caso.
60 minClase 4 + 8
Paso 4 — Módulos 3 y 4
CRM completo + asignación + notificaciones
Conectar el Sheets Update de estado, el Switch de asignación, el nodo Slack y el Google Calendar. Verificar que el vendedor recibe la notificación correcta.
60 minClase 4–5
Paso 5 — Módulo 5
Secuencia de emails con IA y Wait
Email de bienvenida generado por IA. Wait de 1 minuto para prueba. Verificar que llega, que menciona el nombre y el interés. Después cambiar Wait a 1 día.
45 minClase 5 + 8
Paso 6 — Módulo 6
Lógica operacional y SLA enforcement
Añadir el router de tipo de solicitud (soporte/ventas/facturación) y el detector de prioridad. El Wait de SLA se prueba con 1 minuto. Verificar que el escalado funciona.
60 minClase 6 · Parte 2
Paso 7 — Módulo 7
Integraciones externas (APIs)
Añadir la llamada a la API de enriquecimiento (Clearbit o Apollo). Verificar que los datos del lead se enriquecen correctamente y se guardan en Sheets.
45 minClase 7
Paso 8 — Módulo 8
Logging completo y Error Trigger
Añadir el nodo de log al final de cada rama. Configurar el workflow de Error Trigger. Probar que un error forzado llega al canal #errores de Slack.
45 minClase 9
Paso 9 — Pruebas end-to-end
Probar el sistema completo con 10 casos reales
Ejecutar el flujo completo con leads de diferentes segmentos, tipos de solicitud y niveles de prioridad. Verificar que cada uno termina en el estado correcto en Sheets.
60 minTesting

README + diagrama + video demo

Sección 7

Logging, Errores y Observabilidad

Un sistema en producción sin logging es una caja negra. No sabes qué procesa, cuándo falla ni qué leads se perdieron. Esta sección convierte el sistema en observable y auto-reportante.

📝 Patrón de logging — nodo al final de cada rama
// Nodo: Code — preparar entrada de log // Se añade AL FINAL de cada rama del sistema const d = $input.first().json; const inicio = d._ts_inicio || Date.now(); return [{ json: { // ── IDENTIFICACIÓN ──────────────────────────── ts: new Date().toISOString(), lead_id: d.solicitud_id, nombre: d.nombre, email: d.email, // ── QUÉ PASÓ ────────────────────────────────── modulo: d._modulo_actual, ← "M4-asignacion" accion: d._accion, ← "email_enviado" resultado: d._resultado, ← "ok" | "error" // ── CONTEXTO ────────────────────────────────── segmento: d.segmento, prioridad: d.prioridad, vendedor: d.vendedor?.nombre, // ── PERFORMANCE ─────────────────────────────── duracion_ms: Date.now() - inicio }}]; // Siguiente nodo: Sheets Append → hoja "Log"
⚠️ Error Trigger — workflow separado de manejo global
// Workflow: "Manejador Global de Errores" // Trigger: Error Trigger (se activa automáticamente // cuando cualquier workflow activo falla) Nodo 1: Error Trigger Nodo 2: Code — extraer contexto del error const err = $input.first().json; return [{ json: { ts: new Date().toISOString(), workflow: err.workflow.name, nodo: err.execution.lastNodeExecuted, error: err.execution.error.message, datos: JSON.stringify( err.execution.data ).slice(0,400) }}] Nodo 3: Slack → canal #errores-automatizacion Nodo 4: Sheets → hoja "Errores" → registrar Nodo 5: IF → si es tercer error del mismo tipo → email urgente a dev
📊 Dashboard en Sheets — fórmulas clave
// Hoja "Dashboard" — columna B (valores) // B2 — Total leads esta semana =COUNTIFS(Leads!A:A,">="&HOY()-7) // B3 — Leads por estado =COUNTIF(Leads!F:F,"Nuevo") =COUNTIF(Leads!F:F,"Contactado") =COUNTIF(Leads!F:F,"Cliente") // B6 — Tasa de conversión =IFERROR(B5/B2*100,0)&"%" // B7 — Tiempo promedio de respuesta (horas) =AVERAGEIF(Log!D:D,"email_enviado",Log!H:H) /3600000 // B8 — Leads sin atender > 3 días =COUNTIFS(Leads!F:F,"Nuevo", Leads!A:A,"<"&HOY()-3)

Entregable Final del Curso

Lo que debes tener funcionando al terminar la Clase 10. No es solo un workflow: es un sistema completo, documentado y listo para el mundo real.

🏆 Checklist del proyecto final
  • ✓
    Sistema funcionando end-to-end
    Un lead enviado al webhook pasa por todos los módulos: validación → scoring → CRM → asignación → email IA → seguimiento → log. Sin intervención manual en ningún punto.
  • ✓
    8 módulos conectados y funcionando
    Cada módulo tiene su propio workflow en n8n. El módulo M1 llama a M2, M2 llama a M3, etc. Un módulo puede fallar sin romper los demás.
  • ✓
    IA integrada en scoring y redacción
    El Módulo 2 usa IA para refinar casos ambiguos. El Módulo 5 usa IA para redactar los emails. Las respuestas son distintas para cada lead.
  • ✓
    Google Sheets con las 4 hojas configuradas
    Hojas Leads, Log, Errores y Dashboard funcionando. El dashboard muestra métricas reales calculadas por fórmulas, no manualmente.
  • ✓
    Error Trigger configurado y probado
    Un error forzado en cualquier módulo llega al canal #errores-automatizacion de Slack y se registra en la hoja Errores. El sistema nunca falla silenciosamente.
  • ✓
    Probado con 10 leads de prueba distintos
    Al menos 2 por segmento (VIP, caliente, medio, frío) + 2 con datos inválidos. Todos terminan en el estado correcto en Sheets.
  • ✓
    README escrito y workflows exportados
    README con instrucciones de instalación paso a paso. Los 8 workflows exportados en JSON. Cualquier persona puede instalar el sistema desde cero siguiendo el README.
  • ✓
    Video demo de 3 minutos grabado
    Muestra el flujo completo: enviar un lead → ver el email de bienvenida → ver la notificación en Slack → ver la fila en Sheets → ver el log. Sin explicaciones largas, solo el sistema en acción.
