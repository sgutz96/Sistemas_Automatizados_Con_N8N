Acciones en n8n

Las acciones son el resultado visible de tu automatización. Todo lo que ocurre "hacia afuera": notificaciones, registros, mensajes, actualizaciones.

🎯 El principio de las acciones

Un workflow sin acción no hace nada útil en el mundo real

El trigger dispara, los nodos transforman, pero la acción es lo que el mundo ve. Un email que llega, un registro que aparece en Sheets, un mensaje en Slack, una fila nueva en la base de datos. Sin acción, la automatización existe solo dentro de n8n.

Acción 1 de 7

Email — Gmail / SMTP

La acción más universal. Envía emails automatizados, personalizados, con adjuntos o en HTML. Si el mundo usa email, tu workflow puede hablarle por ahí.

📧
Gmail · SMTP · Email personalizado
Envía emails desde tu workflow
n8n puede enviar emails a través de Gmail (con OAuth2), cualquier servidor SMTP, o servicios como SendGrid y Mailgun. Cada email puede estar completamente personalizado usando datos del workflow: nombre, pedido, fecha, monto, lo que necesites.
✉️ Personalizado por destinatario 🎨 HTML o texto plano 📎 Con adjuntos 👥 CC / BCC 🔁 Masivo con Loop
⚙️ Configuración básica
// Nodo: Gmail o Send Email Para: {{$json.email}} Asunto: "Tu pedido #{{$json.id}} fue confirmado" Cuerpo: Hola {{$json.nombre}}, Tu pedido por ${{$json.monto}} COP llegará el {{$json.fecha_entrega}}. Equipo de Logística // Opcional CC: ventas@empresa.com Adjunto: {{$binary.factura}}
📌 Cuándo usar Email
✅
Confirmaciones — pedidos, registros, citas, pagos
✅
Alertas internas — notificar al equipo de eventos críticos
✅
Onboarding — bienvenida automática a nuevos clientes o usuarios
✅
Reportes — enviar resumen semanal con datos del período
✅
Seguimiento — recordatorios a leads sin respuesta en X días
❌
No usar para notificaciones urgentes o tiempo real — Slack/Telegram son más rápidos
E-commerce
🛍️ Confirmación de compra
Pago aprobado en Stripe → n8n genera email personalizado con resumen del pedido, total y fecha de entrega estimada → envío automático
Stripe → Gmail → cliente
SaaS / Producto
👋 Email de bienvenida con onboarding
Usuario se registra → webhook → Set construye email con nombre, plan y pasos de inicio → Gmail envía con adjunto de guía rápida en PDF
Registro → Gmail + PDF → usuario
Agencias
📊 Reporte semanal al cliente
Cron lunes 8am → extrae métricas → Function construye resumen HTML con tablas y números → Gmail envía reporte con diseño profesional
Schedule → Gmail HTML → cliente
Ventas / CRM
🔔 Seguimiento a leads fríos
Cron diario → CRM → filtra leads sin contacto en 5 días → Loop → Gmail envía recordatorio personalizado a cada vendedor con su lista
Loop → Gmail x vendedor
💡
HTML en el cuerpo: usa el modo "HTML" del nodo Gmail para enviar emails con diseño: colores, tablas, botones. Mucho más profesional que texto plano.
⚠️
Límites de Gmail: Gmail tiene límite de ~500 emails/día en cuentas personales. Para envíos masivos usa SendGrid, Mailgun o AWS SES vía HTTP Request.

Google Sheets

La base de datos del equipo no técnico. Con n8n puedes leer, escribir, actualizar y buscar filas automáticamente en cualquier hoja de cálculo.

📊
Google Sheets · Leer · Escribir · Actualizar
Tu base de datos sin código
Google Sheets actúa como una base de datos ligera y visual que todos en el equipo pueden ver y editar. Con n8n puedes escribir filas nuevas automáticamente, leer datos para procesarlos, actualizar celdas específicas o buscar registros por cualquier columna.
➕ Agregar fila 📖 Leer filas ✏️ Actualizar celda 🔍 Buscar registro 🗑️ Eliminar fila
⚙️ Operaciones principales
// APPEND — agregar fila nueva Hoja: "Leads 2025" Valores: A: {{$json.nombre}} B: {{$json.email}} C: {{$json.telefono}} D: {{$now}} E: "pendiente" // READ — leer todas las filas Hoja: "Clientes" Retorna: array de objetos JSON // UPDATE — actualizar celda Fila: {{$json.rowIndex}} Columna: E Valor: "enviado"
📌 Cuándo usar Sheets
✅
Registrar eventos — leads, pedidos, inscripciones, logs de actividad
✅
Panel visible para el equipo — todos pueden ver los datos sin entrar a n8n
✅
Fuente de datos — leer lista de clientes para enviar emails masivos
✅
Dashboard manual — actualizar estado de procesos en tiempo real
❌
No usar para datos críticos con millones de registros — usa DB real

Slack

Notificaciones instantáneas para equipos. El canal donde tu workflow habla directamente con las personas que necesitan actuar.

💬
Slack · Mensajes · Canales · DMs
Tu workflow habla con tu equipo al instante
Slack es el canal de notificación más adoptado en empresas tech y startups. n8n puede enviar mensajes a canales, DMs a personas específicas, mensajes formateados con bloques, o incluso crear threads. Ideal para alertas que requieren acción humana inmediata.
📢 Canal público 🔒 Canal privado 💬 DM directo 🎨 Bloques con formato 🧵 Thread
⚙️ Mensajes con formato Block Kit
// Mensaje simple Canal: #alertas-operaciones Texto: "🔴 Stock bajo: {{$json.producto}}" // Mensaje enriquecido (Block Kit) [{ "type": "section", "text": { "type": "mrkdwn", "text": "*🔔 Nuevo lead*\n Nombre: {{$json.nombre}}\n Email: {{$json.email}}\n Fuente: {{$json.fuente}}" } }] // DM a persona específica Usuario: @juan.perez
📌 Cuándo usar Slack
✅
Alertas urgentes — errores en producción, stock agotado, pagos fallidos
✅
Notificar al equipo — nuevo lead, nuevo cliente, hito alcanzado
✅
Asignación automática — DM al responsable con la tarea que le toca
✅
Resúmenes diarios — métricas del día a las 6pm en canal de resultados
❌
No usar para comunicaciones con clientes externos — es canal interno
Desarrollo / DevOps
🚨 Alerta de error en producción
Sistema detecta error → webhook a n8n → analiza severidad → IF crítico: DM al dev de guardia + mensaje en #incidentes con stack trace
App error → Slack #incidentes + DM
Ventas
🏆 Notificación de deal cerrado
CRM registra deal ganado → n8n envía mensaje a #ventas con nombre del cliente, monto, vendedor responsable y emoji de celebración 🎉
CRM → Slack #ventas
Operaciones
📦 Pedido listo para despacho
ERP marca pedido como preparado → n8n notifica en #logística con número de guía, cliente y dirección → operario ve la tarea sin abrir el ERP
ERP → Slack #logística
Marketing
📈 Resumen diario de métricas
Cron 6pm → extrae datos de Ads + Analytics → Function calcula variación vs ayer → Slack envía resumen formateado al canal de marketing
Schedule → Slack #marketing

Telegram Bot

El canal de notificación más rápido y fácil de configurar. Un bot de Telegram conectado a n8n puede llegar a ti, a tu equipo o a tus clientes en segundos.

✈️
Telegram Bot · Personal · Grupal · Canal
Notificaciones al instante, sin costo
Crear un bot de Telegram y conectarlo a n8n toma menos de 10 minutos. A partir de ahí, tu workflow puede enviarte mensajes, imágenes, archivos o alertas a ti, a tu equipo en un grupo, o broadcast a miles de suscriptores en un canal. Sin costo extra.
💬 Mensaje de texto 🖼️ Imagen / archivo 👥 Grupo de equipo 📢 Canal broadcast 🆓 Sin costo
⚙️ Configuración en 3 pasos
// Paso 1: Crear el bot Abrir @BotFather en Telegram Escribir /newbot Guardar el TOKEN que te da // Paso 2: En n8n Credenciales → Telegram Pegar el TOKEN del bot // Paso 3: Configurar nodo Chat ID: tu_chat_id o @nombre_canal Texto: "🔔 Nuevo lead: {{$json.nombre}}" // Para grupos: agrega el bot // y obtén el chat_id del grupo
📌 Cuándo usar Telegram
✅
Notificaciones personales — alertas que solo tú necesitas ver al instante
✅
Equipos pequeños — grupo de Telegram del equipo como canal de alertas
✅
Sin Slack — alternativa gratuita cuando el equipo no usa Slack
✅
Clientes en canal — actualizaciones broadcast a clientes suscritos
✅
Monitoreo 24/7 — alertas de sistema que necesitas ver en el celular de noche
Freelancers / Fundadores
💰 Alerta de pago recibido
Pago confirmado en Wompi/Stripe → n8n envía Telegram al fundador: "💰 Pago de $350.000 COP de Laura García recibido" — al instante, donde esté
Pago → Telegram personal
E-commerce
📦 Pedido nuevo en tienda
Nuevo pedido en Shopify → webhook → n8n envía a grupo de Telegram del equipo: producto, cliente, dirección y monto. Todos ven el pedido de inmediato
Shopify → Telegram grupo
Comunidades / Cursos
📢 Novedades del curso
Publicación de nuevo módulo → n8n envía mensaje al canal de Telegram del curso: "🎓 Nueva clase disponible: Parte 4 - Acciones". Broadcast a todos los alumnos
CMS → Telegram canal
DevOps / Monitoreo
🔴 Caída de servidor
Monitor detecta downtime → webhook → n8n clasifica severidad → Telegram al responsable de turno: "🚨 Servidor API caído. Tiempo: 2 min. Acción requerida."
Monitor → Telegram DM urgente
Acción 5 de 7

WhatsApp Business

El canal donde están tus clientes. Con la API de WhatsApp Business, n8n puede enviar mensajes automatizados, confirmaciones y notificaciones directamente al celular del cliente.

📱
WhatsApp Business API · Meta Cloud API
Llega al celular de tu cliente
WhatsApp tiene las tasas de apertura más altas de todos los canales: más del 90% de los mensajes son leídos en los primeros 5 minutos. n8n se conecta vía Meta Cloud API (gratuita hasta cierto volumen) o proveedores como Twilio y 360dialog para enviar mensajes con plantillas aprobadas.
📤 Plantillas aprobadas 🖼️ Imagen + texto 📎 Documentos 90% apertura 🌍 API de Meta
⚙️ Envío via HTTP Request a Meta API
// HTTP Request → Meta Cloud API URL: https://graph.facebook.com/v18.0/ {{PHONE_NUMBER_ID}}/messages Método: POST Auth: Bearer {{ACCESS_TOKEN}} Body: { "to": "{{$json.telefono}}", "type": "template", "template": { "name": "confirmacion_pedido", "language": { "code": "es" }, "components": [{ "type": "body", "parameters": [ { "text": "{{$json.nombre}}" }, { "text": "{{$json.num_pedido}}" } ] }] } }
📌 Consideraciones clave
✅
Confirmaciones transaccionales — pedidos, citas, pagos, envíos
✅
Recordatorios — citas médicas, renovaciones, vencimientos
✅
Seguimiento de envíos — número de guía, estado del pedido
⚠️
Plantillas: Meta debe aprobar los mensajes antes de enviarlos — no puedes enviar texto libre sin plantilla aprobada
⚠️
Opt-in requerido: el cliente debe haber aceptado recibir mensajes de tu empresa para cumplir políticas de Meta
Salud / Clínicas
🏥 Recordatorio de cita médica
24h antes de la cita → Cron → consulta agenda → Loop por cada paciente → WhatsApp: "Hola Carlos, te recordamos tu cita mañana a las 10am con el Dr. López"
Schedule → WhatsApp recordatorio
Restaurantes / Delivery
🍕 Confirmación de pedido
Pedido recibido en sistema → n8n envía WhatsApp al cliente con resumen del pedido, tiempo estimado y link de seguimiento en tiempo real
POS → WhatsApp cliente
Retail / E-commerce
🚚 Notificación de despacho
Pedido despachado en logística → n8n envía WhatsApp con número de guía de la transportadora y enlace de rastreo personalizado
ERP → WhatsApp + guía
Finanzas / Seguros
💳 Alerta de vencimiento
7 días antes del vencimiento de póliza → Cron → Loop clientes → WhatsApp personalizado con fecha, monto y link de renovación
Schedule → WhatsApp renovación

Notion / Airtable

Bases de datos visuales para equipos. n8n puede crear páginas, registros, actualizar propiedades y leer datos de ambas plataformas automáticamente.

📋
Notion · Airtable · Bases de conocimiento
Tu workspace conectado al workflow
Notion y Airtable son el cerebro operativo de muchos equipos modernos. Con n8n puedes crear páginas de Notion automáticamente, agregar registros a bases de Airtable, actualizar propiedades, leer datos para procesarlos y sincronizar información entre múltiples plataformas.
📄 Crear página/registro ✏️ Actualizar propiedad 🔍 Buscar registros 📖 Leer base de datos 🔗 Sincronizar plataformas
⚙️ Notion — Crear página en base de datos
// Nodo: Notion → Create a page Base de datos: "CRM Clientes" Propiedades: Nombre: {{$json.nombre}} Email: {{$json.email}} Estado: "Lead nuevo" Fuente: {{$json.origen}} Fecha: {{$now}} Asignado: "Sin asignar" // Airtable — Crear registro Base: "appXXXXXXXXXXXX" Tabla: "Leads" Campos: Nombre: {{$json.nombre}} Stage: "Prospecto"

CRM → Notion página proyecto

Formulario de feedback enviado → n8n crea registro en Airtable con texto del feedback, rating, categoría y usuario → equipo lo revisa en vista Kanban

Contenido / Marketing

Solicitud de contenido por formulario → n8n crea tarea en Notion con título, formato, fecha límite, responsable y la mueve a "Backlog" en el Kanban
Formulario → Notion tarea

Bases de Datos

Para producción real con volumen. MySQL, PostgreSQL, Supabase y MongoDB se conectan directamente a n8n para leer, escribir y actualizar registros desde el workflow.

🗄️
MySQL · PostgreSQL · Supabase · MongoDB
El backend de tus automatizaciones serias
Cuando los datos superan a Google Sheets o necesitas transacciones, índices y consultas complejas, conectas directamente a la base de datos. n8n tiene nodos nativos para MySQL, PostgreSQL y MongoDB, y Supabase se integra vía su API REST. CRUD completo desde el workflow.
SELECT · INSERT UPDATE · DELETE 🔐 Conexión segura 🚀 Alto volumen ⚡ Supabase REST
⚙️ Consultas SQL en n8n
// INSERT — registrar nuevo lead INSERT INTO leads (nombre, email, telefono, fuente, created_at) VALUES ('{{$json.nombre}}', '{{$json.email}}', '{{$json.telefono}}', '{{$json.fuente}}', NOW()) // SELECT — buscar cliente por email SELECT * FROM clientes WHERE email = '{{$json.email}}' LIMIT 1 // UPDATE — cambiar estado del pedido UPDATE pedidos SET estado = 'enviado', updated_at = NOW() WHERE id = {{$json.pedido_id}}

SaaS / Producto
👤 Activar cuenta tras pago
Webhook de Stripe → pago confirmado → n8n hace UPDATE en PostgreSQL: activa la cuenta del usuario, asigna plan y registra fecha de activación
Stripe → PostgreSQL UPDATE
E-commerce / Logística
📦 Registrar pedido en MySQL
Checkout completado → n8n inserta pedido en MySQL (productos, cantidades, cliente, dirección) → actualiza inventario → confirma por email
Checkout → MySQL INSERT+UPDATE
Analytics / Reporting
📊 Pipeline de datos diario
Cron nocturno → n8n extrae datos de múltiples APIs → transforma con Function → INSERT masivo en Supabase → dashboard se actualiza automáticamente
APIs → Supabase INSERT
CRM interno
🔄 Sincronizar contactos
Formulario de contacto → n8n busca si el email ya existe (SELECT) → si existe: UPDATE datos; si no: INSERT nuevo registro → notifica en Slack
SELECT → UPDATE/INSERT
🔒
Seguridad: nunca pongas credenciales de base de datos directamente en el nodo. Usa las Credentials de n8n que las almacena cifradas. Además, usa un usuario de DB con solo los permisos necesarios (principio de mínimo privilegio).
